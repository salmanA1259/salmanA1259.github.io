Employee Deductions Dashboard

Problem Every month HR combined four separate payroll workbooks by hand, and employees had no clear way to see why money was deducted from their pay.

What I built A secure web app where HR uploads the month’s files, reviews automatic data checks, previews every statement and publishes in one step. 03AI Resume Screening Assistant 03

AI • Talent intelligence

AI Resume Screening Assistant

Problem Recruiters screening a stack of CVs for one role have to read every file to find the evidence that matters, which is slow and inconsistent.

What I built An app that reads PDF, Word and scanned resumes (with OCR), extracts skills, experience and education, and ranks candidates against a job description using MiniLM semantic embeddings and an XGBoost learning-to-rank model — showing the evidence behind every score. Recruiter ratings go to a private Google Sheet without names or CV text, and the model is retrained only after it passes a validation check.

Result Built on 11,389 resumes across 108 job categories, including 8,906 scanned documents that needed OCR, with Sentence Transformers and FAISS powering fast semantic search. Designed for human review: scores are advisory and protected characteristics are never used.

  • Python
  • NLP
  • Sentence-Transformers
  • FAISS
  • XGBoost
  • Learning to Rank
  • OCR
  • Streamlit
  • FastAPI
